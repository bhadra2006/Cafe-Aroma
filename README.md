## 📌 Project Overview

**Café Aroma** is a modern and responsive café website created to build a strong digital presence for a local café business.

The website provides customers with an attractive and user-friendly experience where they can explore the café's atmosphere, menu items, and contact details. The design focuses on a clean layout, elegant visuals, smooth navigation, and a professional business presentation.

This project was developed as part of a website development task to create a complete business website using frontend technologies.
